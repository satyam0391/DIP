# Digital Image Processing (DIP) Laboratory Work

## 📘 Repository Description
This repository contains a structured collection of laboratory experiments and practical implementations carried out as part of the **Digital Image Processing (DIP)** coursework.  
The contents reflect hands-on exploration of core image processing techniques and their real-world applications.

---

## 🎯 Scope of Work
The experiments are designed to apply computational methods for processing, enhancing, and analyzing digital images.  
Each task bridges the gap between theoretical learning and practical implementation.

---

## 🔍 Key Areas Explored
- Digital image fundamentals and representation  
- Image enhancement and contrast improvement  
- Spatial domain operations  
- Bit-plane slicing and image decomposition  
- Histogram analysis and equalization  
- Huffman & Shannon coding for image compression  
- Wavelet-based image transformation  
- Basic filtering and edge detection techniques  
- Creative tasks like Tambola ticket generation  

---

## 🛠️ Technologies Used
- **Matlab**

---

## 📁 Folder Organization
Each experiment is placed in its own directory and typically includes:
- Source code (`.m`)
- Sample input images
- Output images/results
- Supporting notes (where applicable)

Examples of experiment directories:
- `DIP_Basic_Operations`  
- `DIP_Bit_Slicing`  
- `DIP_Histogram_Equalization`  
- `DIP_Huffman Coding`  
- `DIP_Shannon Coding`  
- `DIP_Tambola Ticket`  
- `DIP_Wavelet Transform`  

---

## 🎓 Purpose
The goal of this repository is to:
- Strengthen practical understanding of DIP concepts  
- Provide a structured reference for laboratory-based learning  
- Document experiment results for future revision and academic use
